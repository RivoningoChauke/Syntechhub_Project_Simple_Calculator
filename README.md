# SyntechHub Simple Calculator

A command-line calculator developed as part of the SyntechHub Python Programming Internship.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Input validation
- Division-by-zero handling
- Clear option
- Repeated calculations
- Exit option

## Technologies Used

- Python

## How to Run

1. Make sure Python is installed.
2. Open a terminal in the project folder.
3. Run:

```bash
python calculator.py
